# Rapha Gerard — Engineering Portfolio

A beginner-friendly, static engineering portfolio built with HTML, CSS, and JavaScript.

## Preview locally

Open `index.html` in your browser. No server or installation is required.

## Edit your details before publishing

- In `index.html`, replace `YOUR_EMAIL@example.com` with your real professional email.
- Replace `https://www.linkedin.com/` with your actual LinkedIn profile URL.
- Confirm the name, degree, graduation date, experience descriptions, project summaries, and skill statements are accurate.
- The current projects are **summaries of work in progress**, not completed case studies. Replace or expand them as you finish them.
- Only add photos, code, calculations, and capstone details that you're permitted to share publicly.

## Publish to GitHub Pages

1. Create a GitHub repository named `YOUR_GITHUB_USERNAME.github.io` (replace with your actual GitHub username; make it public).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` from this folder to the **root** of the repository. Commit the upload to the `main` branch.
3. Go to your repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**. Select **main**, **/(root)**, then save.
5. Your site will appear at `https://YOUR_GITHUB_USERNAME.github.io/`. GitHub notes that publication may take several minutes.

See official docs: https://docs.github.com/en/pages/quickstart

## Project files

- `index.html`: wording, sections, links, content
- `style.css`: colors, layout, spacing, responsive design
- `script.js`: mobile menu and copyright year
